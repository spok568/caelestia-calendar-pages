Конфиденциальность

Caelestia Calendar — личная интеграция Google Calendar с локальным дашбордом Linux. Эта политика описывает именно приложение и его информационный сайт.

Какие данные доступны приложению

После твоего согласия Google предоставляет список календарей и доступ к событиям календарей, владельцем которых ты являешься. Синхронизация использует основной календарь: названия, даты и время, напоминания, а также описание и место события, когда они присутствуют. Приложение может создавать, изменять и удалять события по твоим действиям в панели.

Для доступа используются разрешения calendar.events.owned и calendar.calendarlist.readonly. Приложение получает OAuth-токены для фонового обновления. Оно не запрашивает пароль Google, доступ к почте, контактам или Google Drive.

Зачем используются данные

Данные используются для показа календаря, передачи изменений между панелью и Google, сохранения локальных заметок и отправки напоминаний. Общая тудушка и таймер не передаются в Google Calendar.

Данные календаря не продаются, не используются для рекламы, профилирования или обучения моделей. Приложение не имеет сервера разработчика, получающего содержимое календаря.

Где хранятся данные

События сохраняются в твоём Google Calendar. Локальные копии записей, журнал синхронизации и резервные копии находятся на твоём компьютере. OAuth-клиент и токены хранятся в отдельных личных каталогах; файлы учётных данных доступны только владельцу по стандартным правам файловой системы Linux.

Синхронизация обращается напрямую к Google по HTTPS. Google обрабатывает переданные ему данные согласно своим условиям и политике конфиденциальности. Доступ других устройств к этому же Google-календарю настраивается тобой отдельно.

Удаление и отзыв доступа

Ты можешь отозвать разрешение Caelestia Calendar в разделе подключений Google-аккаунта. Это прекращает доступ приложения, но само по себе не удаляет события из Google и локальные копии.

Чтобы удалить локальные данные, сначала останови синхронизацию, затем удали соответствующие записи, токены и резервные копии на компьютере. Пути перечислены в README приложения. При работающей синхронизации удаление связанной записи из панели также удаляет соответствующее событие Google; удаление в Google отражается в панели.

Данные посетителей сайта

Этот информационный сайт не получает OAuth-токены или события календаря. На нём нет аналитических скриптов, рекламных инструментов и форм сбора данных. При размещении на GitHub Pages хостинг может обрабатывать технические сведения о посещении, такие как IP-адрес, согласно политике GitHub.

Ограниченное использование данных Google

Использование и передача данных, полученных через Google API, ограничиваются описанными здесь функциями и должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

По вопросам доступа и данных обратись к владельцу личной установки: адрес поддержки указан на экране согласия Google для этого приложения.
